# 🎙️ Assistente de Voz com IA

## 📌 Descrição

Projeto desenvolvido como desafio prático utilizando Inteligência Artificial para criar um assistente de voz.

O sistema permite:
- 🎤 Converter áudio em texto (Speech-to-Text)
- 🤖 Gerar resposta com IA
- 🔊 Converter texto em áudio (Text-to-Speech)

---

## 🚀 Tecnologias Utilizadas

- Python
- OpenAI API
- Whisper (Speech-to-Text)
- gTTS (Text-to-Speech)
- Google Colab
